CONTROL MASIVO DE PRECIOS

Catálogo, costos y márgenes

Regla: los costos de proveedor no se publican. El sistema guarda únicamente los precios IMPERIA calculados y sus márgenes. La referencia de mercado nunca se convierte automáticamente en costo.

Aplicar a muchos productos

Para calcular precios reales se necesita costo proveedor. Si no existe costo, el sistema no inventa uno ni transforma la referencia pública en costo.

Cotización mayorista

Pega CSV o texto tabulado con ID, SKU o referencia, costo. Ejemplo: IMP-001,SKU123,18500. El sistema buscará el producto, calculará los tres precios y guardará solo los precios calculados.

Importar archivo de cotización / nuevo proveedor

Sube CSV, TSV, TXT, JSON o PDF. Los PDF se conservan como documento de proveedor en el repositorio; los demás formatos se procesan para precios. El sistema identifica por ID, SKU, referencia o nombre, evita duplicados y aplica 20% mayorista / 25% contratista / 35% retail. Los costos quedan solo en esta sesión.
